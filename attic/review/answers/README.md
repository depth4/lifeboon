# Answers from the panel

One file per answer, saved **verbatim**, named `<model>-<topic>.md`, e.g.
`gemini-terrain.md`, `deepseek-junctions.md`.

Verbatim, because the point of keeping them is to check later what a model
actually said against what happened when it was tried. A summary cannot be
checked.

Put at the top of each file: which model, which date, and — this is the part
that gets forgotten — **which files it was given**. An answer from a model that
saw only the source code means something different from one that read
`BRIEF.md` first. See `review/PANEL.md`.
